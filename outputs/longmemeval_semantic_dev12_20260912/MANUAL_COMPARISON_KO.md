# 기존 답변의 잠정 의미 판정

**채점자: Codex가 원문 답변을 직접 판독. GPT-4o API 공식 판정이 아니다.**
공식 LongMemEval rubric을 참고했으며, 방법명과 기존 결과를 이미 본 상태라 blind 평가도 아니다. 기존 답변과 기준 정답은 변경하지 않았다.

| 방법 | 정답/판독 문항 | 잠정 정답률 |
|---|---:|---:|
| Full-context | 10/12 | 83.33% |
| Seed · MiniLM | 10/12 | 83.33% |
| r40 · MiniLM | 8/12 | 66.67% |
| Refined · MiniLM | 7/12 | 58.33% |
| Seed-parent · MiniLM | 10/12 | 83.33% |
| LangMem | 0/1 | 0% |
| SimpleMem | 1/1 | 100% |
| LightMem | 1/1 | 100% |

마지막 세 방법은 공통 통근시간 문항 하나뿐이다. 12문항 또는 전체500 성능을 의미하지 않는다. 자체 네 방법은9/10 Qwen3.5-9B+MiniLM 조건이다.

## 판정 규칙과 모호한 사례

1. 시간 유형은 공식 rubric의 ±1 규칙을 적용했다. 2개월에3개월, 2주에3주, 4일에3일을 정답으로 인정했다.
2. 답변 길이·서식으로 감점하지 않았다. 질문에서 단위가 명확한4,12도 각각4일,12회로 인정했다.
3. Full-context의 두 계산 답변은 합계를 거부했지만 필요한 두 피연산자를 모두 담았다. 공식 rubric의 중간 과정 허용 조항을 적용해 정답으로 판정했다. **거부를 우선해 둘 다 오답으로 보면 Full-context는8/12=66.67%**다.
4. 통근시간 답변은 Full-context가45분을 다른 사용자 정보라고 명시하고 자기 사용자의 답은 모른다고 했으므로 오답으로 판정했다. LangMem Unknown도 오답. SimpleMem·LightMem·자체4방법은 편도45분을 답했으므로 정답이다. Full-context의 숫자 언급만으로 정답을 인정하는 관대한 해석이면 Full은11/12가 되지만 본 판정은 그렇게 처리하지 않았다.
5. 추천 영상은 기준 정답에 제목과URL이 있어 둘 다 요구했다. 자체4방법은 제목만 있어 오답으로 처리했다. **제목만으로 충분하다고 허용하면 Seed11/12(91.67%), r409/12(75%), Refined8/12(66.67%), Seed-parent11/12(91.67%)**다.
6. Full의 건강 문제 순서 답변은 핵심 답이 맞아 정답으로 판정했다. 불필요한 부연에 시간상 이상함이 있지만 요청한 순서를 뒤집지는 않았다.

위 대안은 해석 차이이며 통계적 신뢰구간이나 공식 judge의 예상 결과가 아니다. 기존 F1를 정확도로 읽는 오류는 바로잡을 수 있지만, 이 판정으로 정밀한 방법 우위를 확정할 수는 없다.
