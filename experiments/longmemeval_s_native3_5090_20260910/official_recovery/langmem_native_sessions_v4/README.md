# LangMem v4: fixed Qwen non-thinking memory decoder

This is a separate LongMemEval integration and serving adaptation, not an official LangMem LongMemEval reproduction or an unchanged-decoder baseline. It retains the authentic LangMem/Trustcall source and all v3 source-session mapping, prompts, memory algorithm, native three-attempt tool repair, retrieval and benchmark QA. See ../langmem_native_sessions_v3/README.md and source_manifest.json for the inherited source identities and response-artifact contract.

Only memory-model sampling now uses the Qwen3.5-9B model card's fixed general non-thinking recipe: temperature0.7, top_p0.8, top_k20, min_p0.0, presence_penalty1.5, repetition_penalty1.0. Source: https://huggingface.co/Qwen/Qwen3.5-9B#best-practices, inspected2026-09-10. The memory output cap8192 and SDK retry count0 remain explicit operational limits from v3; the8192 cap is not the model card's recommended output budget or an upstream extraction default. QA and embeddings are unchanged.

The v3 shared full-history smoke completed41/53sessions, then received finish_reason=length after8192completion tokens, with no usable tool calls. It failed and was not retried. A separately metered single-request diagnostic used the same6096-token input with the fixed model-card recipe and returned four tool calls in411completion tokens,8.58seconds. This establishes one successful diagnostic response, not general reliability or better benchmark accuracy. No gold answer, question type, or benchmark score selected these settings. The invalid v3 attempt and diagnostic remain preserved separately.

The runner asserts all six sampling values in every outgoing memory SDK request. Full raw SDK and HTTP request/response artifacts remain hash-bound; headers are excluded. Truncation, filtered/empty required-tool output, transport failure and unhandled native errors still fail the history. Native handled PatchDoc losses are separately counted in sealed native_degradation.json and are never described as lossless writes.

Use fresh runs/langmem_native_sessions_v4 and the no-automatic-retry autonomy_r4 controller. Failed histories require diagnosis before any retry; the controller cannot replace failure with fewer scored examples. Model, upstream, runtime and dataset provenance must pass the new server gate before launch.
